# NES 控制台配色参考

本文件记录项目中所有用到的颜色，按区域分组。

|------|------|-----|------|
| 菜单区底色 | `#2D2D2D` | 45, 45, 45 | 菜单铺满时的底色 |
| 其他区域底色 | `#282828` | 40, 40, 40 | 侧边栏、顶栏、底栏 |
| 选中项填充 | `#212227` | 33, 34, 39 | 比底色更暗，Ozone 招牌特征 |

| 选中项文字 | `#00D9AE` | 0, 217, 174 | 青绿色 |
| 正文文字 | `#FFFFFF` | 255, 255, 255 | 白色 |

| 分隔线 | `#51514F` | 81, 81, 79 | 列表项之间 |

| 光标边框色 0 | `#198AC6` | 25, 138, 198 | 动画光标起始色 |

### 游戏中半透明背景

游戏中呼出菜单时，背景为半透明渐变（让后面的画面透出来）：

| 位置 | 颜色 | Alpha |
|------|------|-------|
| 顶部 | `rgba(45, 45, 45, 1.0)` | 1.0 |
| 中部 | `rgba(45, 45, 45, 0.94)` | 0.94 |
| 底部 | `rgba(45, 45, 45, 0.75)` | 0.75 |

公式对应 Ozone 默认 `framebuffer_opacity = 0.9`：
- 顶部 alpha = 0.9 / 0.9 = 1.0
- 底部 alpha = 2.5 × 0.9 − 1.5 = 0.75

## 屏幕外（中性石墨 + 一支强调青）

外围刻意只留一个色相：屏幕内是照抄 RetroArch Ozone 的灰 + 青，外围再自带一套颜色
就是两套语言在同一页上打架（原先是「复古未来」的深紫 + 霓虹紫，已整体换掉，
包括从没被引用的 `--nes-*` / `--neon-rose` / `--neon-gold` 那十几条）。

### 背景层次

| 用途 | 颜色 | RGB | 变量 |
|------|------|-----|------|
| 渐变外圈（最深） | `#0B0B0D` | 11, 11, 13 | `--bg-primary` |
| 渐变中心 | `#1A1A1E` | 26, 26, 30 | `--bg-accent` |
| 背景网格线 | `rgba(255,255,255,0.025)` | — | `--stage-grid` |
| 摆放模式工具条底 | `rgba(38,38,43,0.94)` | — | 直接写在 `.layout-editor` |

### 强调色

| 用途 | 颜色 | RGB | 变量 |
|------|------|-----|------|
| 按下描边 / 拖入 ROM 边框 / 摆放框 | `#7FD8F5` | 127, 216, 245 | `--accent` |
| 按下填充 / 主按钮底 | `rgba(89,198,232,0.34)` | — | `--accent-fill` |
| hover 底、1px 细边、虚线框 | `rgba(127,216,245,.18/.5/.85)` | — | 同一支换 alpha |

填充档比 `--accent` 深一档：半透明的提亮色压在近黑底上会发灰，看不出「按下了」。

### 手柄材质

| 用途 | 颜色 | 变量 |
|------|------|------|
| 键的底色（未按下） | `rgba(226,232,240,0.09)` | `--pad-surface` |
| 键的描边 | `rgba(148,163,184,0.45)` | `--pad-line` |
| 描边粗 | `3px` | `--pad-line-w` |
| 按下 | 引用上面的 `--accent-fill` / `--accent` | `--pad-press` / `--pad-press-line` |

方向键四片、六个按键、屏幕内的菜单按钮都读这一组，所以它们看着是一套东西。

### 文字层次

| 用途 | 颜色 | RGB |
|------|------|-----|
| 浅色文字 | `#E2E8F0` | 226, 232, 240 |
| 次要文字 | `#94A3B8` | 148, 163, 184 |

## 对比度实测

屏幕内（Ozone）：

| 组合 | 对比度 | WCAG AA |
|------|--------|---------|
| 正文 白 on `#2D2D2D` | 13.77 | ✅ |
| 选中文字 青绿 on `#212227` | 8.72 | ✅ |
| 次要文字 `#9F9FA1` on `#2D2D2D` | 5.21 | ✅ |
| 选中描边 青 on `#212227` | 5.45 | ✅ |

屏幕外（石墨 + 强调青）：

| 组合 | 对比度 | WCAG AA |
|------|--------|---------|
| 强调青 `#7FD8F5` on 渐变中心 `#1A1A1E` | 10.78 | ✅ |
| 强调青 `#7FD8F5` on 渐变外圈 `#0B0B0D` | 12.21 | ✅ |
| 键名文字 `#E2E8F0` on 按下填充（压成 `rgb(47,84,99)`） | 6.63 | ✅ |
| 键名文字 `#E2E8F0` on 未按下底色（压成 `rgb(44,45,49)`） | 11.16 | ✅ |

半透明底色要先和它下面的背景（这里取渐变中心 `#1A1A1E`）合成一个实色再算，
直接拿 `rgba` 里的 RGB 算出来的是错的。按下时文字到 6.63 仍达 AA（正文要求 4.5），
所以键名在按下的瞬间不会糊掉。

测试文件：`agent-workspace/verify-ozone-colors.cjs`
